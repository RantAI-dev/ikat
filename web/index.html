Placement Is Provenance: Anchor-Preserving Ingestion for Figure-Grounded Retrieval-Augmented Generation

A layout parser already knows where every figure belongs — its position in the block sequence says so exactly. Conventional ingestion throws that ordering away and spends the rest of the pipeline trying to reconstruct it from captions. This binds it instead, at the one moment the information still exists.
